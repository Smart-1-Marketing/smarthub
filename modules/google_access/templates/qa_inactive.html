Find GA4 properties with no events or sessions in the last {{ window_days }} days, plus GTM containers with no confirmed traffic in the same window. GTM has no traffic-reporting API of its own, so a container GA4 confirms alive is skipped and read active — nothing else about the linked property (inactive, unreachable, not visible to this login) holds a container back as inactive here. Every remaining GTM container is checked automatically instead: this scan fetches its resolved website and looks for the container's own tag in the raw HTML. A confirmed find moves it out of the deletable candidates and into Needs Review, because the tag is genuinely on the page and that is a person's call, not this scan's. A Check site button on every GTM row runs the same check on demand, for a site the automatic pass could not resolve or to double-check one by hand. Every section also works in bulk {{ help_dot('google_access.cleanup.bulk') if help_dot is defined else '' }} — tick the rows you mean and use the buttons above each table.
