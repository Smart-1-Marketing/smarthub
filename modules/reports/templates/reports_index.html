Upload a CSV {{ help_dot('reports.index.upload') if help_dot is defined else '' }}

A platform's own export, for a platform with no feed connected or a month a feed missed.

One row per campaign-day, with a date, an account or advertiser id and a campaign id — those three are required and a file without them is refused naming the columns it has — plus campaign name, spend, impressions, clicks and conversions where the export carries them (listens and completions for audio). A row for a campaign-day already in the table replaces it; a row that cannot be true is held in quarantine rather than filed; and the platform's sync row says csv wrote it, because a hand upload is not the feed.
