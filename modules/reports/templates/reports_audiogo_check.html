Set AUDIOGO_API_KEY and AUDIOGO_API_BASE on the service. The base is called exactly as it is set — set it to the whole report endpoint and leave AUDIOGO_REPORT_PATH alone, or set it to the origin and put the rest in that variable (- clears it again). The method, header and parameter names can be overridden the same way (AUDIOGO_METHOD, AUDIOGO_BODY, AUDIOGO_AUTH_HEADER, AUDIOGO_PARAM_START, AUDIOGO_FIELD_SPEND ...) while a correction is tried; the settled answer belongs in audiogo_map.py. AudioGo describes a report as a query of filters, splitters and metrics, so if this GET is refused, AUDIOGO_METHOD=POST sends the dates as a JSON body instead.
