SELF-HOSTED BRAND LOGOS
=======================

Drop official SVGs here named after the domain. The page tries this folder FIRST,
so anything you add is used forever, loads instantly, and works even if the logo
CDN is down or blocked by a corporate network.

Missing files fall back automatically: CDN -> favicon -> plain wordmark. Nothing
ever renders as an empty box, but the wordmark is not as strong as the real logo.

Most of these are on the brand's press / media kit page. White or single-colour
versions work best — the marquee renders them white via CSS, so a dark-only logo
will still come out white.

Add or change the marquee list in PROVIDERS, and the domain map in BRAND_DOMAINS,
both inside public/index.html.
