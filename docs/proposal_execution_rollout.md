# Proposal Execution rollout

Ship as an internal MVP first and validate with Monogram Homes before enabling it as the standard path for every proposal.

The rollout check is behavioral, not visual: the proposal must parse into the expected channel graph; one shared-input answer must unblock multiple tasks; background work must continue after leaving the page; Radio Scripts must create a real artifact; and every external activation must stop at approval/handoff until a person records the real platform action.
